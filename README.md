# Auto Nexus for RotMG (Realm of the Mad God)
## One of my first coding projects!

This is a minimal, working version of an "auto-nexus" script for the game Realm of the Mad God. I built this primarily for entertainment and to challenge myself with some early automation concepts.

The main trick is reading a pixel on the screen until the health bar turns red (implying low health). At which point the character will automatically return to a safe spot.

### Disclaimer

This was developed purely for educational/entertainment purposes. It is not intended for reproduction or active use. It has not been tested on different operating systems or game clients.
